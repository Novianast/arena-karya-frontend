# Arena Karya Frontend

Arena Karya is a web-based competition management platform developed as a collaborative academic project.

## My Role
As a Front-End Developer, I contributed to:
- Judge Profile page
- Participant Profile page
- Profile image upload using Supabase Storage
- Province & City dropdown
- Front-end implementation with Next.js

## Tech Stack
- Next.js
- React.js
- TypeScript
- Tailwind CSS
- Supabase
- PostgreSQL
